# The Developer's Journey

Комікс-портфоліо: скрол програє сторінки коміксу по панелях. Vite + React + TypeScript + GSAP (ScrollTrigger) + Lenis.

    npm install
    npm run dev       # локально
    npm run build     # tsc + vite build -> dist/

## Де що лежить
- `src/story.json`: весь комікс (сітка сторінок, панелі, елементи, тайминг, тексти). Позиції в % панелі, `at` і `d` на шкалі 0..1.
- `src/components/Comic.tsx`: одна закріплена сцена й головна GSAP-timeline; `BookPage` (обкладинка), `placeClimb` (підйом сходами).
- `src/components/ChapterNav.tsx`: навігація по розділах (назви беруться зі `story.json`).
- `src/components/ProjectsModal.tsx`: вікно проєктів (focus trap, блок скролу).
- `src/config.ts`: ім'я, контакти, посилання, список проєктів.
- `src/sound.ts`: звуки через Web Audio API (без файлів). Клавіша `M` вмикає/вимикає звук.
- `public/assets/`: графіка у WebP; `og.jpg` для прев'ю в соцмережах.

## Режими
- Десктоп (≥900px завширшки **і** ≥560px заввишки): одна закріплена сцена, скрол програє комікс.
- Телефон, планшет у портреті, телефон у ландшафті: панелі йдуть одна під одною, кожна програється **один раз сама**, коли заходить в екран (без прив'язки до довжини сторінки).
- `prefers-reduced-motion` або кнопка «Пропустити анімацію»: статичний комікс, усе у фінальному стані.

Межі режимів задані в двох місцях, які мають збігатися: `DESK_MQ` у `src/layout.ts` і медіа-запити в `src/styles.css`.

## Адаптив: як тримаємо персонажів у кадрі
- `.actor` (styles.css): позиція й висота беруться з `story.json` (`x`, `b`, `h`), але спрайт ніколи не ширший за панель, а його центр відсунутий від країв рівно настільки, щоб він не вилазив. Працює для панелі будь-якої форми.
- `placeClimb` (Comic.tsx): герой і значки навичок на сходах притиснуті до меж панелі.
- Пропорції панелей у стековому режимі рахує `stackRatio` (src/layout.ts) із сітки десктопа, у межах від 1:1 до 1.8:1. Панель зі сходами має пропорцію самої картинки, тож нічого не обрізається.
- Якщо додаєш анімацію, яка навмисно виходить за рамку (`to` з великим `xPercent`), пам'ятай: `xPercent`/`yPercent` рахуються від розміру **панелі**, а не персонажа.

## Екран завантаження, звук і курсор
- `src/preload.ts` + `src/components/Loader.tsx`: перед стартом підвантажуються й декодуються всі картинки та шрифти (список у `PRELOAD`, **додаєш нову картинку в `public/assets`: додай її й туди**). Поки екран увімкнений, скрол заморожений. Кнопка «Почати» дає справжній жест користувача, тож звук стартує без попереджень браузера.
- Звук: `AudioContext` створюється лише в `sound.unlock()` усередині кліку/клавіші/`touchend` (у `Comic.tsx`). `wheel` і `touchstart` жестом не вважаються.
- `src/components/SwordCursor.tsx`: курсор-меч (`sword.webp`), вістря меча = позиція вказівника. Нахиляється за рухом, світиться над кнопками й посиланнями, на клік замахується з іскрами та «БАМ!». Лише для миші й без `prefers-reduced-motion`, інакше лишається звичайний курсор. Слова змінюються в `WORDS`.

## Деплой на Vercel
1. Імпортуй репозиторій у Vercel: Framework Preset `Vite`, Build Command `npm run build`, Output Directory `dist` (це значення за замовчуванням).
2. Адреса для `og:image`, `og:url` і `canonical` підставляється сама з `VERCEL_PROJECT_PRODUCTION_URL`.
   Для власного домену додай змінну `SITE_URL` (наприклад `https://example.com`).
3. Кеш для `/assets/*` налаштований у `vercel.json`.
4. Після деплою перевір прев'ю посилання в Telegram / Facebook Sharing Debugger.
